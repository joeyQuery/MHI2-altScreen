# MHI2 AltScreen

Reverse-engineering and implementation research for native CarPlay AltScreen (secondary display) on Audi MHI2.

This repository treats the validated MHI2Q AltScreen implementation as the functional specification and records the evidence required to reproduce that architecture on MHI2.

See `STATUS.md` and `docs/README.md`.
